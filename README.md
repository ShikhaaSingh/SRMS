# SRMS — AI-Powered Student Result Management System

**Tech Stack:** Java, Spring Boot, MongoDB, HTML5, CSS3, JavaScript

SRMS is a full-stack Student Result Management System designed to simplify and automate student grade management. The application provides RESTful APIs for managing student records and includes performance analytics to help with academic decision-making.

### 🚀 Key Features

* **Student Result Management:** Built a full-stack web application using **Java, Spring Boot, and MongoDB** to manage and automate academic records for **500+ student records**, reducing manual data-entry effort by approximately **50%**.
* **RESTful APIs:** Developed **5+ REST APIs** supporting CRUD operations for efficient creation, retrieval, updating, and deletion of student and result data.
* **Performance Analytics:** Added analytics features to help visualize and evaluate student academic performance for easier decision-making.
* **Fast API Responses:** Optimized backend operations to maintain typical API response times of **under 200ms**.
* **MVC Architecture:** Followed a clean **MVC-based architecture** to keep the application modular, maintainable, and easier to extend.
* **AI-Assisted Development:** Used **ChatGPT** during development for debugging, code improvement, and implementation support, helping reduce development time by approximately **30%** while maintaining code quality.
* **Responsive Frontend:** Built the user interface using **HTML5, CSS3, and JavaScript** for a simple and responsive user experience.
